# Queen’s Domain COOP

[English](README.md) | **简体中文**

Queen’s Domain COOP 是一款支持双人局域网合作的 Mod。你可以与朋友一起探索世界、挑战敌人和 Boss。

按 [安装说明](INSTALL.md) 完成一次安装后，直接从原版启动器或 Steam 启动游戏。MOD通过游戏内新增的多人菜单主持房间，或输入房主的 IP 与端口加入游戏。

除同一局域网外，也可以使用 **Radmin VPN** 等虚拟局域网工具连接。

## 联机教程

**房主需要承担额外的世界模拟、敌人 AI 和同步开销，推荐由电脑配置较高的一方主持游戏。**

1. **双方安装。** 使用相同版本的游戏和 Mod，将完整 Mod 包解压到游戏根目录，关闭游戏后运行一次 `Install.cmd`。随后通过原版启动器或 Steam 正常启动；如果设置过旧版 Mod 的 Steam 启动项，请先清空。详细步骤见 [安装说明](INSTALL.md)。
2. **连接到同一网络。** 在同一局域网内可直接连接。若不在同一局域网，双方可使用 Radmin VPN：一方创建网络，将网络名称和密码告诉队友，另一方加入该网络，并保持 Radmin VPN 运行。参见 [Radmin VPN 官方教程](https://www.radmin-vpn.com/help/)。
3. **房主开房。** 在主菜单进入「多人游戏」，确认「房间端口」（默认 `47771`），选择「主持游戏」，再选择存档并进入世界。进入后房间开启，等待队友加入。
4. **队友加入。** 在主菜单进入「多人游戏 → 加入游戏」，输入房主的 IPv4 地址和相同端口，点击「连接」。连接成功后，选择自己的角色存档，进入房主的世界。同一局域网使用房主的局域网 IPv4；使用 Radmin VPN 时，填写 Radmin VPN 中显示的房主 IP，不能填写自己的 IP 或 `127.0.0.1`。
5. **如果连接超时。** 先确认房主已进入世界、双方 IP 和端口填写正确，以及 Radmin VPN 中双方在线。检查 Windows 防火墙是否允许 `QDCoopBridge.exe` 在当前使用的网络上通信；默认房间使用 UDP `47771`，修改端口后以房主设置为准。

目前最多两人游玩。1.17.3 共用原版存档，建议首次联机前保留存档备份。

## 合作与进度

世界进度以房主为准，包括机关、开门、可破坏捷径、Boss 战斗阶段和战斗结束后的通路。特殊 Boss 对话与过场动画由房主主导，游戏内传送也以房主的操作为准。书本放置解谜由房主操作，并向客机同步结果。

客机保留自己的角色、装备、经验和个人拾取进度。原版场景中的可拾取物品由各自独立拾取。双方击杀怪物也可以按原版规则获得各自的掉落。

1.17.3 的联机与单人模式使用原版存档目录，不再隔离。启动时会备份现有存档到 `QDCoop-Direct/Backups`；旧版隔离存档不会自动导入。任意玩家保存时，双方共同保存世界进度与各自的角色状态。

## 倒地与救援

一名玩家倒地后，队友可以面对倒地玩家，**按住 E 进行救援**。救援进度使用原版蓝色蓄力条显示，松开 E 即中断。

- 若当前选中的是回血道具，救援成功时消耗一个，并按该道具的回复量救起队友。
- 若未选中回血道具，则不消耗物品，以 1 点生命值将队友救起。
- 所有玩家都倒地后，自动读取最近一次完整的共同存档，恢复到最后保存的进度。

## 同步与动作表现

为了让原本的单人游戏能够共同游玩，Mod 为玩家、敌人和世界交互补充了同步机制。

**第三人称玩家动作**

利用原版角色、武器与动画素材，并结合重新制作和适配的动作，为游戏添加了一整套第三人称表现，包括走路、跑步、跳跃、视线俯仰、武器握持、蓄力、攻击和倒地。不同武器保留各自的动作特点，并同步远程投射物、武器特效与音效。

这些动作尽量由各端本地播放，通过同步动作状态与进度保持一致，减少持续搬运骨骼姿态的开销。移动则通过插值与平滑处理，缓和网络更新间隔带来的跳动。

**敌人与战斗**

同步敌人的位置、朝向、动作、生命值、死亡以及攻击特效和声音。怪物可以追击并攻击双方玩家；仇恨选择结合距离、近期伤害与可见性，并抑制两人交替攻击时的频繁换目标。

敌人表现尽量复用原版动画和效果，在本地连续播放。战斗结果由房主协调，客机的攻击参与共同结算。

**怪物仇恨如何选择目标**

怪物的合作模式仇恨由房主统一计算，综合考虑双方玩家的位置、近期造成的实际伤害和可见性。

- **距离与伤害共同影响选择。** 距离越近，越容易吸引注意；近期造成的实际生命值损失越多，仇恨评分越高。伤害按最近约 3 秒的滑动窗口统计，并随时间逐渐衰减。因此，高频投掷飞刀不会仅凭命中次数获得额外优势，较早的一轮爆发也不会长期锁住仇恨。
- **视野与遮挡参与判断。** 正前方约 90°、且没有遮挡的玩家会获得可见性优势。从背后造成伤害也能引起注意，但不会赋予怪物穿墙视野。目标短暂躲到障碍后时，怪物可以保留约 1 秒的记忆，并参考最后可见位置继续追击。
- **换目标需要足够的理由。** 目标仍有效时，通常至少保持约 1.5 秒；另一名玩家的评分还需明显超过当前目标，才会切换。攻击和收招期间也有短暂的目标保持，减少两人轮流攻击时怪物反复转身的情况。
- **双方都能承担仇恨。** 客机在房主世界中拥有用于追击、命中和伤害判定的代理，使怪物能够真正攻击客机。倒地、死亡、离开有效范围等状态也会影响目标选择。部分由剧情脚本指定目标的特殊攻击仍遵循原版逻辑。

**世界交互**

除同步机关和场景状态外，也尽量保留开门、开箱、隐藏通路等交互的动画与声音。Boss 的阶段切换、死亡结算、屏障解除，以及过场结束后的操作恢复，也纳入了同步处理。

## 为联机做出的调整

多人游戏中，背包、图鉴、暂停菜单、武器进化等功能不再暂停整个世界。打开这些界面时，其他玩家与敌人仍会继续行动；部分原版演出仍会暂时限制正在观看演出的玩家操作。

为了兼顾流畅度与同步效果，我们逐步将进程间通信改为共享内存，减少高频文件读写；优化对象查找、怪物采集、特效更新与动画处理；并将大量远端动作改为本地动画播放。设计上，本地视角和移动不等待网络包，网络主要负责传递状态、动作与交互结果。

## 当前状态

目前支持 **一名房主与一名客机**。Mod 仍在持续完善，复杂场景、特殊敌人与网络条件可能影响同步表现和性能。建议双方使用相同版本，并在更新前保留联机存档备份。
